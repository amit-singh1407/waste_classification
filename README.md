# ♻️ Waste Detection System using YOLOv8

An AI-powered Waste Detection and Classification System built using **YOLOv8**, **Python**, and **Gradio** for smart recycling and waste management.

---

## 🚀 Features

* Real-time Waste Detection
* Image Classification using YOLOv8
* Video Waste Detection Support
* Interactive Gradio Web Interface
* Adjustable Confidence & IoU Thresholds
* Fast and Accurate Predictions
* Deployable on Hugging Face Spaces

---

## 🛠️ Technologies Used

* Python
* YOLOv8 (Ultralytics)
* Gradio
* OpenCV
* Pillow
* PyTorch
